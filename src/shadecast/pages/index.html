shadecast

Given a city and a budget, which cooling measures should you build, and where?

shadecast is an open, credential-free pipeline that turns any city into an urban heat decision problem. It assembles a city from open data, runs the SOLWEIG radiation physics over it, learns a surrogate of the response so that search becomes affordable, and then asks the inverse question: not how much cooler a given intervention makes a place, but which interventions a given budget should buy, and where.

  • Proposal The research proposal: hypotheses, pre-registered experiments and how each is judged.
  • The tree shade surrogate pipeline How the surrogate is built, trained and judged, with every number taken from a model manifest or a recorded run.
  • Source and issues The code, the design in its issues, and the command line that runs the whole pipeline.

The interactive walkthrough

The walkthrough draws maps and charts from physics output in the browser, so hovering a pixel reads its temperature. That output is gigabytes of local data, so the walkthrough runs on the machine that holds it, from a checkout of the repository:

uv run sdc dash
Apache-2.0. Physics by SOLWEIG, run as a separate process under its own license.
