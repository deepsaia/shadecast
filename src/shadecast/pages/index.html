Heatwave Resilient Cities

Given a city and a budget, which cooling measures should you build, and where?

A simulator of urban heat adaptation, built from open data with no account, key or quota. Pick a city and one of its square-kilometre tiles, choose the policy, the design under it and how much to build, and the outcomes answer at once: the drop in radiant heat exposure, the degree-hours removed, the people brought below a stress threshold you set, the change in the equity gap, and the cost. Behind each answer is a surrogate learned from SOLWEIG radiation physics run over that very tile, with the engine-verified designs kept on every chart beside it, so the surrogate is always seen against the physics.

  • Proposal Why the problem matters, what the physics found when the first tiles were run, and the limits the project holds itself to.
  • The tree shade surrogate pipeline How a tile is built, simulated and learned from, with every number taken from a model manifest or a recorded run.

Running it

The simulator draws its maps and charts from physics output in the browser, so hovering a pixel reads its temperature. That output is gigabytes of local data, so it runs on the machine that holds it, from a checkout of the repository: build the client once, then serve it with the API, and the simulator opens as the first page. The same questions are answered from the command line by sdc.

make frontend
uv run sdc serve
